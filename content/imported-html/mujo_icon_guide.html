Icon Guide v1.0
Mujo Icon Guide · v1.0 · April 2026

The icon system. Every rule, every file.

This document is the single source of truth for every icon used in any Mujo surface — website, packaging, social templates, emails, decks, partner co-marketing. It contains the six botanical illustrations in the working set, the functional markers (dots, arrows, stars), usage rules, size specs, and a commission brief for whoever extends the set later. If an icon isn't here, it's not in the system yet.

Icon philosophy. Quiet, organic, inevitable.

Mujo's icon system takes its cues from the apothecary tradition — hand-drawn botanical illustrations that feel like they could be rendered on the inside cover of a 1920s herbal dispensatory, then pared back for a modern minimalist system. The guiding principles:

1 / Ingredient-first

Every primary icon is a real ingredient from the Mujo formula, not a generic symbol. "Calm focus" is Lion's Mane, not a brain. "Lower cortisol" is an Ashwagandha root, not a stress meter. This makes the visual system inseparable from the product — the icons teach the ingredient story even when the copy doesn't. It's also a competitive moat: no other brand's benefit icons look like this.

2 / Single weight, single colour

All botanical icons are drawn at 1.1–1.2px stroke weight in sage (#2F3D33) on light backgrounds, or cream (#F3F2E9) on sage backgrounds. Never orange. Never filled. Never gradient. This restraint is what gives the system its editorial quality — the eye reads them as illustrations, not UI.

3 / Slight organic imperfection

The icons use rounded line caps and slight variance in stroke — a curve that isn't perfectly regular, a leaf that's a touch asymmetric. This is the difference between "designed by a human who cared" and "generated by an icon library." Reinforce this if you commission more.

4 / Paired with DM Mono attribution

When an icon represents an ingredient, it's paired with a DM Mono caption that names the ingredient ("Lion's Mane fruiting body · 8:1"). This is a specific brand pattern — it turns every benefit callout into a subtle ingredient credit. Use this pattern in every benefits section going forward.

The rules. Do and don't.

Do
Use botanicals for benefit callouts. Map each benefit to a real ingredient in the formula (focus → Lion's Mane, energy → Cordyceps, etc.).
Don't
Use generic "benefit" icons like lightbulbs for focus, flames for energy, moons for sleep. Generic icons belong to every wellness brand. Botanicals belong to us.
Do
Keep botanicals sage-only. #2F3D33 stroke on cream/sand backgrounds. Cream stroke (#F3F2E9) if the icon sits on a sage background.
Don't
Colour icons orange. Orange is reserved for CTAs, wordmark, and italic accents only. Orange-filled icons look like wellness industry.
Do
Use line weight 1.1–1.2px consistently across all icons. Rounded line caps. Small organic imperfections are good.
Don't
Mix stroke weights or styles. A thin botanical next to a fat geometric icon breaks the system. All icons follow the same hand.
Do
Pair each icon with a DM Mono attribution naming the ingredient: Lion's Mane fruiting body · 8:1. This is the signature pattern.
Don't
Use emoji anywhere. They render differently on every device (iOS vs Android vs Windows) and carry no brand voice. 🍄 → botanical SVG.

What's forbidden. Don't even consider these.

A short list of things that are never acceptable in the Mujo icon system, even if someone suggests them:

  • Emoji — render differently per device, no brand voice, wrong cultural register
  • Generic icon libraries (Heroicons, Material Icons, Feather, Lucide, Font Awesome) — every competitor uses them
  • Filled / solid shape icons — break the line-illustration register, read as enterprise software
  • Gradient fills — always flat colour, never blended
  • Orange as primary icon colour — orange is reserved for CTAs and italic accents only
  • AI-generated icon sets — MidJourney or similar for icons — inconsistent, uncanny, identifiable as AI within the year
  • Stock illustrations — Shutterstock, Freepik, NounProject — traceable and used by every small brand

Benefits section. The canonical pattern.

The way botanical icons appear on a page is tightly specified. Follow this pattern every time you build a benefits / features section. Doing anything else breaks the system.

Structure

  1. Eyebrow: DM Mono, 11px, 0.2em letter-spacing, orange-deep (#D85A22), uppercase, with 22px horizontal rule accent before text
  2. H2: General Sans 500, v2 scale clamp(26px, 2.8vw, 36px), with Instrument Serif italic orange accent flowing inline (no <br>)
  3. Lede: General Sans 400, 16px, line-height 1.65, max-width 680px, center-aligned
  4. Card grid: 3 columns desktop, 2 columns tablet, 1 column mobile, 16px gap
  5. Each card contains: 48px botanical SVG → benefit h3 (General Sans 600, 19px) → 1-sentence body (14px, line-height 1.6) → DM Mono ingredient attribution (10px, 0.12em tracking)

Card container

Cream background (#F3F2E9) on a sand section background (#EEE9E0), border-radius 18px, padding 36px 32px 32px. Hover: lift 3px, shift background to white, border-color to sage-light.

Botanical icon spec

48px × 48px, SVG viewBox 0 0 48 48, sage stroke (#2F3D33) at weight 1.1–1.2px, rounded line caps. 22px margin-bottom before the h3.

Attribution line

The DM Mono line at the bottom that names the ingredient is mandatory. It's the pattern that ties the benefit to the formula. Border-top above it (1px sage-light with opacity), 14px padding-top.

Size reference. Where each size goes.

Botanical icons are designed at 48px base. They scale cleanly from 20px to 200px. Use the sizes below as defaults for their contexts.

20px · inline compact

ingredient lists
feature pills
inline references

For inline or compact contexts where an icon sits next to a small label. Maintains full recognition at this size.

32px · UI default

ingredient cards
table rows
dense grids

The UI default. Use in ingredient cards, comparison tables, and any grid denser than 3 columns.

48px · benefits default

benefit cards
feature sections
3-col grids

The canonical benefits section size. Used in the "Six shifts" pattern across homepage and PDP.

72px · hero moments

deep-dive sections
editorial callouts
social templates

For prominent moments — ingredient spotlight blocks, single-benefit editorial cards, social post templates where the icon is the visual anchor.

120px+ · packaging and print

packaging
print brochures
large-format

Very large applications where the icon becomes a graphic element. At this scale, consider commissioning a higher-fidelity hand-drawn version rather than scaling the 48px working file.

Commission brief. If you hire an illustrator.

The six-icon set is production-ready. But if you want to upgrade to a professional hand-drawn set for packaging or extend the system with more icons (Bacopa, Maca, MCT, the Lemna Bar ingredients when it launches), here's the brief to send a freelance illustrator.

Copy the brief below
Looking for: A freelance illustrator to produce a 10-12 icon botanical set in a hand-drawn apothecary style for a wellness brand. References: Aesop packaging, Moon Juice botanical illustrations, SUPA, Diptyque candle labels.

Specs: Single-weight line illustrations, 1.1–1.2px stroke, sage #2F3D33. Delivered as optimized SVG with 48×48 viewBox, plus 120px raster versions for packaging. Subtle organic imperfection welcomed; no perfectly geometric forms. Rounded line caps throughout.

Scope: Lion's Mane (fruiting body), Cordyceps militaris, Ashwagandha (root), Rhodiola (flower + leaves), Chaga (on birch), Cacao (pod), plus [future ingredients: Bacopa, Maca, MCT source (coconut), Lemna leaf, and 2-3 reserves].

Timeline: 3 weeks with 2 rounds of revisions. Budget: $2,500–4,500. Deliverables: source Illustrator/Figma files, individual SVG files, PNG exports at 512px, brand style documentation.

Where to find someone

Dribbble (filter for "botanical, illustration, hand-drawn, apothecary"). Working Not Working. Contra. Behance — look for illustrators who've worked with apothecary or herbal brands. Portuguese illustrators often have a strong hand for this style if you want someone local. Ask to see sketch process and previous single-weight line work, not just final icon sets.

Adding new icons. When the set extends.

When the Lemna Bar launches or when a new benefit story emerges, new icons will need to join the set. These rules apply:

1 / Stay within the set's style

New icons must match the existing stroke weight, cap style, organic feel, and 48×48 viewBox. Think of each new icon as a sibling to the existing six, not a cousin.

2 / Extend from ingredients, not concepts

When a new benefit is introduced, map it to a real ingredient. If the ingredient is new to the formula, commission a new botanical icon. If it's a concept (e.g. "sleep"), use the closest existing botanical (Rhodiola already covers sleep).

3 / Document the addition

When a new icon joins the system, update this guide with: the SVG code, the icon-id, the Latin name, the benefit mapping, and the attribution line. Bump the guide's version from v1.0 to v1.1.

4 / Priority candidates for v1.1

The icons most likely to be commissioned next:

  • ic-lemna · Lemna minor, floating leaf — for the Lemna Bar launch
  • ic-maca · Lepidium meyenii root — high-altitude energy, hormonal balance
  • ic-bacopa · Bacopa monnieri leaf — memory consolidation, learning
  • ic-curcumin · Turmeric root — cognitive inflammation, mood (only if Longvida gets a visual)
  • ic-coconut · C8/C10 MCT source — sustained cognitive energy
